Engineering

Every iteration should leave a trace.

AquaSense uses design–build–test–learn cycles to connect a problem, a prototype, an observation, and a concrete change—without pretending a concept study is a finished device.

01 · Method

Learn before adding.

The engineering cycle is treated as a decision record—not a decorative loop.

Each cycle begins with one uncertainty, selects the lowest-cost prototype that can expose it, and ends with an explicit change. Because this is a concept project, “build” includes interface mockups, architecture diagrams, and failure-mode analyses rather than fabricated laboratory work.

02 · DBTL cycles

Three uncertainties, three changes.

Select a cycle to inspect the evidence trail. The interactions are keyboard accessible and preserve a linear reading order without JavaScript.

Cycle 01 · Interface

Make the signal interpretable

D
Design

Begin with a continuous color gradient representing reporter intensity.

B
Build

Prototype a printed reference scale and a circular reaction window.

T
Test

Five volunteer readers classified simulated colors under two lighting conditions.

L
Learn

Adjacent colors were difficult to distinguish and a gradient implied false precision.

Change carried forward

Replace the gradient with three named bands, icons, and written next steps.

Cycle 02 · Reliability

Separate signal from failure

D
Design

Use one reaction window to display the target-responsive output.

B
Build

Map the sample path from inlet through the freeze-dried reaction pad.

T
Test

Run a failure-mode review covering insufficient volume, expired reagents, and incomplete activation.

L
Learn

A blank window could mean either a low result or a test that never ran.

Change carried forward

Add a separate procedural control and make “invalid” a first-class result state.

Cycle 03 · Biosafety

Contain the full sample path

D
Design

House the reaction in a snap-fit two-piece cartridge.

B
Build

Sketch an exploded stack with a sample well, membrane, reaction pad, and absorbent layer.

T
Test

Review opening points, spill paths, disposal behavior, and user handling after activation.

L
Learn

A reusable shell introduced contamination and encouraged reopening after use.

Change carried forward

Move to a sealed single-use cartridge with a one-way inlet and tamper-evident seam.

04 · Validation roadmap

What comes before “works.”

A staged plan prevents a visually compelling prototype from outrunning the evidence behind it.

  1. 01
    Interaction prototype

    Validate language, result hierarchy, and error states with representative users.

    Concept complete
  2. 02
    Molecular feasibility

    Characterize dose response, baseline expression, and time-to-signal in a controlled buffer.

    Proposed
  3. 03
    Selectivity panel

    Challenge the system with copper, zinc, iron, calcium, pH variation, and mixed samples.

    Proposed
  4. 04
    Matrix testing

    Compare performance across tap, surface, and well-water matrices using certified controls.

    Proposed
  5. 05
    Field and usability study

    Evaluate handling, comprehension, transport, storage, and confirmatory-testing uptake.

    Proposed
